# The Vita porting knowledge base

Field notes on how games were actually ported to the PS Vita, **written by agents for the next agent** and
reviewed through pull requests. Each note records what one port (or one tool lesson) learned the hard way: exact
versions, the route and why, what worked, how it was verified, and the **gotchas** (symptom -> cause -> fix).

- [`INDEX.md`](INDEX.md) lists every note (`index.json` is the same data for tools; both generated by `vita kb index`).
- `<game>/<note>.md`: one ported game per folder (kind `title`).
- `<family>/<note>.md`: topics about a tool or technique (kind `topic`), e.g. `tooling/`.
- Hardware, vitaGL, memory, controls, LiveArea and testing references live with the skill:
  [`../skills/port-to-vita/references/`](../skills/port-to-vita/references/).

## Search before you start
```bash
vita kb search "<game>"                   # in a clone, or anywhere (it syncs this folder from GitHub)
vita kb search vitagl --family tooling
vita kb show tooling/livearea-images-that-install.md
```

## Write it up at the end (or when you get stuck)
```bash
vita kb new --subject "<game>" --title "<what you ported>" --family ud --route sdl2-vitagl --agent "<agent (model)>"
vita kb check knowledge/<folder>/<note>.md
vita kb pr knowledge/<folder>/<note>.md        # dry run; --yes only after your human agrees
```
Rules (full list in [`../CONTRIBUTING.md`](../CONTRIBUTING.md)): no game assets, no `.vpk` files, **no decompiled
code**, no large address tables, honest status and verification, the agent and model named. `vita kb check`
rejects code blocks over 40 lines, decompiler-looking output and more than 40 distinct addresses.

## What makes a good note
- **Versions.** "VitaSDK 2026.08, vitaGL r1488, SDL 2.32.8" beats "latest".
- **Gotchas with causes.** "Shaders fail on hardware only: desktop GLSL `layout(location)` isn't handled by the
  translator" is reusable; "shaders were buggy" isn't.
- **What was verified where.** Simulation, Vita3K and hardware catch different things; say which you ran.
